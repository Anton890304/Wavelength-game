# Резонанс

Мобильная игра в духе настольной «Длины волны»: оригинальное оформление, 60 русских пар противоположностей, скрытая цель и подсказки. Две команды по 2–6 человек играют на одном телефоне. Это самостоятельная неофициальная веб-версия, не APK.

## Запуск

Нужен Node.js 18 или новее, установка зависимостей не требуется.

```powershell
node server.cjs
```

На компьютере откройте http://localhost:4173. Для Pixel 7 Pro подключите телефон к той же Wi-Fi сети и откройте в Chrome `http://IP-КОМПЬЮТЕРА:4173`. IPv4 компьютера можно посмотреть командой `ipconfig`. Если соединение блокируется, разрешите Node.js доступ к частной сети в брандмауэре Windows. Сервер оставляйте запущенным.

## Установка на Android и офлайн

Разместите семь файлов интерфейса (`index.html`, `styles.css`, `app.js`, `rules.js`, `sw.js`, `manifest.webmanifest`, `icon.svg`) на статическом хостинге с HTTPS. Затем в Chrome на телефоне откройте адрес и выберите меню ⋮ → «Добавить на главный экран» / «Установить приложение». После первого успешного открытия файлы сохраняются для автономной работы. В обычной локальной сети по HTTP Service Worker и полноценная установка PWA недоступны; в этом режиме игра работает в открытой вкладке браузера.

## Правила

1. Назовите команды и выберите 6, 10 или 14 общих раундов.
2. Ведущий активной команды забирает телефон и открывает секретную цель. Остальные не смотрят.
3. Введите ассоциацию к положению цели между противоположностями, затем скройте цель и передайте телефон команде.
4. Команда обсуждает подсказку, двигает ползунок и открывает цель.
5. Расстояние до центра: до 4 пунктов — 4 очка, до 10 — 3, до 16 — 2, дальше — 0. Шкала содержит 100 пунктов.
6. Команды ходят по очереди и меняют ведущего внутри команды. Побеждает больший счёт после равного числа ходов.

Состояние сохраняется в localStorage телефона. Возвращение к игре не открывает секретный экран автоматически. Новая игра заменяет предыдущую при нажатии «Поехали». Все данные хранятся на устройстве; внешние сервисы не используются.

## Проверки

```powershell
node --test tests/rules.test.cjs
node --check app.js
```

Интерфейс адаптирован под мобильную ширину, включая логические размеры Pixel 7 Pro. Реальная установка и проверка на физическом Pixel требуют телефона и HTTPS-хостинга.

## Вдвоём · просто на интерес

На главном экране выберите «Вдвоём · просто на интерес» и введите имена. Один видит цель и даёт подсказку, второй угадывает. После результата нажмите «Поменяться ролями». Общий счёт не ведётся; точность показывается от 0 до 4. Количество раундов не ограничено. «Закончить игру» завершает партию после любого раунда. Незаконченная игра сохраняется автоматически.
