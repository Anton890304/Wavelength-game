# Резонанс

**Играть онлайн:** https://anton890304.github.io/Wavelength-game/

Мобильная неофициальная игра в духе настольной «Длины волны», с оригинальным оформлением и 60 русскими парами противоположностей. Играйте на одном телефоне. Сайт публикуется автоматически из ветки main через GitHub Pages.

## Вдвоём

Введите имена и выберите 6, 10, 14 раундов или «Без лимита». Один игрок видит секретную цель и вводит подсказку. Второй выставляет стрелку и открывает цель. Очки начисляются угадывающему игроку. В следующем раунде роли меняются. Счёт каждого виден во время игры. «Итоги игры» после последнего раунда и «Завершить игру · показать итоги» в любой момент показывают очки и количество засчитанных ответов каждого игрока. При нечётном числе завершённых раундов число угадываний может отличаться.

## Компания: 2–6 команд и отдельный ведущий

Выберите число команд, их названия и число раундов. Ведущий — отдельный участник, который видит цель и не угадывает. Он даёт одну общую подсказку. Каждая команда по очереди получает телефон, передвигает свою стрелку и сохраняет ответ. Ответы других команд скрыты; для следующей команды стрелка начинает с центра. Только когда все ответы сохранены, появляется кнопка «Открыть цель для всех». После открытия каждая команда получает свои очки, а экран показывает её ответ относительно общей цели. Все команды угадывают в каждом раунде. Можно завершить досрочно и увидеть итоги.

## Очки и сохранение

Расстояние до центра цели: до 4 пунктов — 4 очка, до 10 — 3, до 16 — 2, дальше — 0. Очки начисляются только при открытии цели и ровно один раз за раунд. Досрочное завершение незаконченного раунда сохраняет итог уже открытых раундов. Состояние сохраняется в localStorage, включая ответы команд. Секретная цель не открывается автоматически при возвращении к игре.

Обновлённые правила используют отдельное сохранение v2. Старые партии предыдущей версии не продолжаются по новым правилам, их сохранение не удаляется.

## Android

Откройте HTTPS-ссылку в Chrome → ⋮ → «Добавить на главный экран» / «Установить приложение». После первого открытия ресурсы кэшируются для автономной работы.

## Локальный запуск

Нужен Node.js 18 или новее. Зависимости не требуются.

```powershell
node server.cjs
node --test tests/rules.test.cjs
node --check app.js
```

Локально: http://localhost:4173. Для телефона в той же Wi-Fi сети: http://IP-КОМПЬЮТЕРА:4173. По локальному HTTP полноценная установка и автономная работа могут быть недоступны.
